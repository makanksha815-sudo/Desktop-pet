# 💧 Water Girl – Desktop Water Reminder

A cute desktop water reminder pet built using Electron and Node.js, designed to encourage regular hydration through friendly reminders.

## ✨ Features

- Cute animated desktop companion.
- Automatic water drinking reminders.
- Transparent, frameless desktop window.
- Always-on-top desktop pet.
- Interactive reminder experience.
- Lightweight desktop application.

## 🛠️ Tech Stack

- JavaScript
- HTML
- CSS
- Node.js
- Electron

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Water-Girl
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```
